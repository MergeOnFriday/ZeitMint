# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or exposed credential.

Send a concise report to [devs@zeitmint.com](mailto:devs@zeitmint.com) with:

- the affected component or route;
- steps to reproduce;
- the expected impact;
- any suggested mitigation.

Do not access user data, move funds, publish credentials or test against third-party systems without explicit permission. ZeitMint will acknowledge a report when it is received and coordinate disclosure after a fix is available.

## Current scope

The public product currently includes browser-side builders, JSON exports, Telegram-backed waitlist notifications and an optional testnet provenance experiment. The crypto checkout is a non-transactional demo. No production token deployment, custody or automated payout system is included.
